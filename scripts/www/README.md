# GPT NanoBanana AI出图 - 手机APP版

## 使用说明

### 方法一：直接使用
1. 在浏览器中打开 `index.html` 文件
2. 使用Chrome/Safari/Edge浏览器
3. 在浏览器中即可使用全部功能

### 方法二：安装为手机APP (推荐)

#### Android手机
1. 用Chrome浏览器打开网页
2. 点击右上角菜单 (...)
3. 选择「添加到主屏幕」或「安装应用」
4. 确认后即可在桌面看到APP图标

#### iPhone/iPad
1. 用Safari浏览器打开网页
2. 点击底部中间的「分享」按钮
3. 向下滚动，选择「添加到主屏幕」
4. 点击右上角「添加」即可

## 主要功能
- ⚡ 批量快速出图
- 🖼️ 多参考图融合
- ✏️ 圈选局部修改
- 📦 历史记录导出
